FastSave - Local Version

1. Install Python 3.10 or newer.

2. Open Command Prompt inside the FastSave folder.

3. Run these commands:

   py -m venv .venv
   .venv\Scripts\activate
   py -m pip install -r requirements.txt
   py app.py

4. Open this address in your browser:

   http://127.0.0.1:5000

5. Keep the Command Prompt window open while using the website.

To stop the server, press CTRL+C.

Note:
This is a local development version.
Only download public videos that you own or have permission to save.
Download speed depends on the platform, video size, and internet connection.
